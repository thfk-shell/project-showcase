## 배포

GitHub 저장소 → Settings → Pages → Build and deployment → Deploy from a branch → main / (root) 설정.

배포 주소: `https://thfk-shell.github.io/project-showcase/`

## 공개 관련 주의

- 개인 이름, 학번, 연락처, API 토큰, 패스워드는 포함하지 않습니다.
- 정적 HTML 프로그램은 인증된 데이터 서버가 없으므로 개별 브라우저의 측정 데이터가 자동으로 공유되지 않습니다.
- 시험용 예시 값과 실제 측정값을 혼동하지 않습니다.
- 공개용 라이선스는 지정하지 않았습니다. 공개 저장소라는 사실만으로 무제한 재사용 허가가 부여되지는 않습니다.
