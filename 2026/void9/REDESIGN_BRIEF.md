# VOID9 × Keyboard Studio — 공개 쇼케이스 전면 재설계 지시서

**독자:** 하드웨어·프로그래밍을 잘 모르는 지도교사(최우선), 학교 평가자, AI/메이커 프로젝트에 관심 있는 방문자.
**목표:** 결과의 규모를 시각적으로 강하게 드러내면서도 누가 무엇을 했고 실제로 무엇이 동작했는지 쉽게 이해시키는 **웹 포트폴리오 겸 인터랙티브 전시관**.
**장소:** GitHub Pages, `thfk-shell/project-showcase`, `2026/void9/`. 다른 프로젝트에 영향 주지 마세요.

## 반드시 살릴 이야기
반복적인 컴퓨터 단축키가 번거로워서 맞춤형 입력장치를 직접 만들고 싶었다. 선생님이 제작에 필요한 부품·환경을 지원해 주셔서 직접 VOID9 제작에 도전했다. 3×3 스위치/다이오드/Pro Micro 하드웨어를 조립·납땜하고 실제 QMK 펌웨어를 만들었다. 제작 과정에서 배선 이해가 어렵고 코드·도구가 복잡하다는 문제를 발견해 3D 배선 시뮬레이터와 Keyboard Studio까지 확장했다. 최종적으로 실제 Windows PC에서 Keyboard Studio를 실행하고 VOID9에 펌웨어를 올려 9개 키와 FN 레이어가 정상 작동하는 것을 확인했다. USB 연결 불안정은 GND 접지선 납땜 이탈이 원인이었으며 다시 납땜해 해결했다.

## 보여 줄 핵심 결과물 세 가지
1. 직접 제작한 3×3 매크로패드 VOID9: 스위치 9개, 1N4148 다이오드 9개, Pro Micro ATmega32U4, 3D 출력 케이스.
2. 3D 핸드와이어링 가이드: 3D 회전, 뒷면 배선, 행·열, 다이오드 방향, 단계별 안내, 가상 오류 진단. 기존 별도 배포 기록: https://void9-wiring-simulator.thfk1234kr.chatgpt.site/
3. Keyboard Studio: 사용자 정의 행·열, Pro Micro 핀 선택, 키맵/FN 레이어, QMK 구성 생성·컴파일, USB/부트로더 업로드, 오프라인 Windows 설치본.

## 검증 사실
- VOID9 실물 및 최종 키 입력 9개와 FN 레이어 작동: 제작자의 실제 기기 사용으로 확인.
- GND 재납땜 후 USB 불안정 해결: 제작자의 실제 수리 경험.
- Keyboard Studio 실제 Windows 실행 및 VOID9 펌웨어 업로드 성공: 사용자 검증.
- 자동 테스트는 저장소 별도 기록 기준이며 실기기 시험과 구분.
- 다른 사용자, 다른 MCU, 장기 내구성, 접근성 개선/의학적 효과를 실험해 증명한 것은 아님.
- 개인 프로젝트에서 AI의 역할: 시뮬레이터 및 GUI 구현, 자동 테스트·버그 수정에 도움. 제작자의 역할: 하드웨어 제작·회로 오류 수리, 문제 정의·요구사항·제품 설계 방향·실기기 검증.

## 현재 웹페이지의 불만 / 설계 요구
현재 페이지는 지나치게 정형적인 카드 나열과 가상의 CSS 키보드 모형에 의존해 제품의 존재감을 약화시킬 수 있음. **기존 구조·색상을 보수적으로 다듬는 대신 전면 재설계**하세요. 제안 후 실제 구현까지 수행하되, 사용자에게 20가지 취향을 묻느라 작업을 멈추지 마세요.

디자인 지향:
- 실제 스위치·배선·프로그램 스크린샷을 중심으로 한 강렬한 제품 전시/엔지니어링 포트폴리오.
- 첫 화면에서 '실제로 만든 장치 + 3D 가이드 + 작동 검증된 앱' 관계가 5초 안에 이해될 것.
- 고등학생 활동을 과소평가하지 않도록 대담한 타이포그래피, 절제된 모션, 세련된 편집 디자인. 과장된 자기평가는 근거 없는 주장으로 바꾸지 않음.
- 기술을 모르는 선생님도 이해할 수 있는 실제 문제→제작→막힌 부분→자체 해결 도구→작동 증명의 흐름.
- 사진 클릭 확대, 제작 과정 타임라인, 실제 키맵/FN 전환 미리보기 등 의미 있는 인터랙션만 사용.
- 모바일 Android와 데스크톱에서 가독성/이미지 크기/터치 영역이 좋을 것. 반짝이는 장식과 과한 스크롤 애니메이션은 지양.
- 기술적 깊이가 필요한 사람을 위한 '상세 기술 보고서'는 별도 Google Docs에 존재하며, 사용자 권한 검토 전 문서 링크를 공개 페이지에 추가하지 마세요.

## 기존 코드와 파일
- 수정 대상: `2026/void9/index.html`, `2026/void9/assets/*`, 공개 사이트의 루트 `index.html` 카드(필요 시).
- 기존 물리 실물 사진 및 GUI 화면을 삭제하거나 AI 생성 이미지로 대체하지 마세요.
- `2026/void9/3d-guide/README.md`에 원본 후보 및 복구 이력이 있음. 여기의 사이트 URL은 **역사적 배포 기록**이지, 원본 HTML이 본 GitHub 저장소에 복사되었다는 뜻이 아닙니다.
- 원본 3D HTML을 별도 소스로 확보할 수 있을 때만 `2026/void9/3d-guide/index.html`로 이식해 구동 테스트하세요. 기존 배포 주소에 접근이 안 되면 독자적으로 만들어 낸 새 가이드를 '원래 최종본'이라고 표현하지 말고 원본 요청이 필요하다고 보고하세요.
- 원본 QMK 백업의 Row 핀은 `F4,F5,F6`, Col은 `D3,D4,D2`, diode는 `COL2ROW`. 일부 3D 후보의 Col `D1,D4,D0`과 불일치. 오류 가능성을 숙지하고 실제 배선·QMK 소스에 맞춰 점검할 것.
- `thfk-shell/keyboard-studio`는 **비공개**. 코드/비밀 정보/실험 로그/API 토큰/학번·이름 등 개인 정보를 공개 저장소에 복사하지 말 것.

## 기준 기술·품질
- GitHub Pages의 하위 경로 `/project-showcase/2026/void9/`에 맞는 상대 URL.
- JavaScript 오류 없는 상호작용. 배포는 순수 정적 파일을 우선하고 빌드가 필요한 프레임워크 추가는 이유를 제시할 것.
- 키보드/스크린리더 탐색, aria-label, alt 텍스트, reduced-motion, 텍스트 대비 준수.
- 가능하면 실제 브라우저에서 PC/휴대폰 폭 캡처 후 이미지 잘림, 글줄, 터치, 링크, 로딩 검증.
- 기존 `2026/physics-cooling/` 등의 작업은 건드리지 말 것.
