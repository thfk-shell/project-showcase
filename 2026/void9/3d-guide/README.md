# VOID9 3D 배선 시뮬레이터 V2

`index.html`을 브라우저로 열면 바로 실행되는 학습용 3D 배선 가이드입니다. 설치나 빌드가 필요 없고, 3D 라이브러리(three.js r160, MIT)는 `vendor/`에 포함되어 있어 외부 CDN 없이 동작합니다(웹 글꼴만 Google Fonts를 사용하며, 실패하면 시스템 글꼴로 대체).

- 공개 주소(병합 후): `https://thfk-shell.github.io/project-showcase/2026/void9/3d-guide/`
- 홍보 페이지에서의 상대 경로: `./3d-guide/`

## V2의 성격
- **새로 작성한 프로그램입니다.** 이전 배포본(아래 기록)의 원본 HTML은 이 저장소에 복구되지 않았고, V2 제작 중에도 이전 사이트에 접속하지 못했습니다(작업 환경의 네트워크 정책으로 차단). 이전 화면 캡처(`../assets/simulator.webp`)와 기술 보고서의 기능 설명만 참고했습니다.
- 실제 회로를 측정하거나 진단하지 않는 **교육용 시각화**입니다. 오류 시뮬레이션과 가상 입력 테스트는 미리 정의한 규칙에 따른 결과입니다.

## 정확성 범위
| 항목 | 근거 |
|---|---|
| Rows `F4, F5, F6` / Cols `D3, D4, D2` / `COL2ROW` / Pro Micro / Caterina | VOID9 QMK 백업 `keyboard.json` (`app.js`의 `QMK` 상수) |
| 보드 인쇄 ↔ QMK 핀 (A3=F4, A2=F5, A1=F6, TX0=D3, 4=D4, RX1=D2) | Pro Micro 표준 핀 배치 |
| 다이오드 방향 (캐소드 → 행) | COL2ROW 정의 |
| 전선 경로, 케이스 형상, Pro Micro 위치·방향, GND 선의 연결 대상 | **시각화 모델** (실측 아님) |

모든 배선 끝점은 `QMK` 상수에서 계산되므로 핀 값을 바꾸면 3D 모델과 표가 함께 바뀝니다. 이전 일부 가이드의 열 핀 `D1, D4, D0`은 백업과 다르며, V2에서는 "잘못된 MCU 핀 연결" 오류 시나리오로만 등장합니다.

## 기능
- 3×3 스위치(단자 포함)·키캡, 1N4148 다이오드와 검은 띠, 행/열 배선, Pro Micro와 24개 핀 라벨, 납땜 지점, 케이스 상판·하판
- 시점: 초기화, 윗면, 하판 정면, 하판 사선, Pro Micro 확대 (하판 시점에서는 하판 자동 숨김) / 자유 회전·확대·이동
- 표시 토글: 키캡, 상판(반투명), 하판, 라벨 / R0–R2, C0–C2 개별 강조
- 단계 가이드 8단계: 부품 확인 → 스위치 → 다이오드 → 행 → 열 → Pro Micro → 완성 → 펌웨어 핀 비교
- 오류 시뮬레이션 7종: 다이오드 역방향, 행 단선, 열 단선, 잘못된 MCU 핀, 행·열 접촉, 냉납, GND 연결선 이탈(VOID9 실제 사례). 위치·증상·원인·수정 방법 표시
- 가상 입력 테스트: 3×3 버튼 또는 3D 스위치를 눌러 현재 상태에서 QMK 스캔 결과를 규칙으로 표시
- 부품 클릭(탭) 시 설명, 키보드 조작(뷰포트: 방향키·+/−·R, 탭: 좌우 화살표), `prefers-reduced-motion` 대응, WebGL 미지원 시 안내

## 파일
```text

vendor/      three.module.min.js, OrbitControls.js, CSS2DRenderer.js, THREE_LICENSE.txt
```

## 이전 배포 기록

- 별도 배포 주소 (2026-09-20 당시): https://void9-wiring-simulator.thfk1234kr.chatgpt.site/
- 당시 안내된 기능: 3×3 스위치, 단계별 제작 가이드, 회전 가능한 밑면 배선 모델, 가상 결선 오류의 설명.
- 코드 후보 파일명: `void9_3d_handwiring_simulator.html`, `void9_v2_3d.html`, `void9_simulator.html` (서로 다른 시점·버전).
- 사용자가 최종적으로 승인한 **최신 HTML 소스와 이전 배포 사이트의 바이트 일치 여부는 확인되지 않음**.
- 과거 검토에서는 다이오드/Row 3D 표현과 Pro Micro 핀 라벨을 추가 수정해야 한다는 지적이 있었습니다.

## 실제 VOID9 펌웨어 백업의 기준 설정 (2026-09-30)
```json
{
  "development_board": "promicro",
  "bootloader": "caterina",
  "diode_direction": "COL2ROW",
  "matrix_pins": {
    "rows": ["F4", "F5", "F6"],
    "cols": ["D3", "D4", "D2"]
  }
}
```

일부 기존 HTML 버전은 열 핀을 `D1/D4/D0`으로 보여 줍니다. 위 백업의 `D3/D4/D2`와 불일치하며, 실제 제작 가이드로 공개하기 전에 실물 회로와 교차 확인이 필요합니다. 이를 검증 없이 자동 변경하는 것도 피해야 합니다.

## 향후 마이그레이션 절차
1. 사용자가 확인한 실제 최종 HTML 또는 이전 Sites 프로젝트의 원본 코드를 확보합니다. 확보 실패 시 동일 결과물이라고 주장하거나 새 모델을 원본인 것처럼 꾸미지 않습니다.
2. 원본을 백업한 뒤 공개 저장소 `2026/void9/3d-guide/` 안에 별도로 복사합니다. 기존 쇼케이스 페이지와 다른 파일로 관리합니다.
3. 기능 보존: 회전·줌·밑면 확인·행/열 색상 구별·다이오드 띠 방향·단계별 연결 안내·가상 오류 설명.
4. 실제 VOID9 펌웨어와 핀맵의 일관성을 확인하고, 3D 결선 도형/핀 위치를 눈으로 검사합니다.
5. PC/모바일 작동, 네트워크 라이브러리 의존성, 접근성, 상대경로를 점검한 뒤 URL을 연결합니다.
